# Asset provenance

`assets/namib-coast.webp` is original AI-generated artwork created for this project using the built-in image generation tool on 18 November 2026. It is a Namibia-inspired illustration, not documentary photography. The pilot scope identifies it as AI artwork. It is now a subtle decorative landscape behind the companion. It was compressed locally to WebP for the pilot's page-weight budget; the current optimized version is 960 × 640 (41,566 bytes).

Prompt: “Use case: photorealistic-natural. Asset type: wide website hero photograph-like original artwork, landscape 3:2. Create a breathtaking aerial Namibia-inspired landscape where sculptural burnt orange Namib sand dunes meet the deep turquoise Atlantic ocean, with a slim line of white surf and distant clear pale blue sky. Elegant natural afternoon light, believable fine sand texture, sweeping diagonal dune ridge, expansive composition, rich restrained earth tones. No people, buildings, flags, logos, lettering, text or watermark. Original scene, not a reproduction of any photograph. Save as a project asset.”

The supplied image-search screenshot was only a visual reference; no third-party photographs or website screenshots were incorporated. The custom dune/horizon brand mark and generic line icons are repository-native SVG artwork. Provider marks are monochrome identity cues on unavailable controls; they do not represent provider endorsement or a connected service.


## Companion character

`assets/namib-companion.webp` is an AI-edited cutout of the NamibOne Companion artwork supplied by the user on 18 November 2026. The built-in image-generation editor preserved the friendly illustrated character, short curls, teal/cream outfit, tablet and welcoming hand while removing the landscape, UI cards, input bar, labels and tablet writing. Obscured clothing was reconstructed. The character is fictional and does not represent a verified government official or affiliation.

Edit specification: isolate the supplied character on genuine transparency; preserve identity, pose, clothing and lighting; remove all surrounding interface/text and background; reconstruct clothing hidden by the original UI; add no new character or text.

The source edit was a 1086 × 1448 RGBA PNG. The project asset is optimized to a 680 × 907 transparent WebP (72,470 bytes). CSS animates the image layer only; there is no lip synchronization, video or live avatar provider. Essential text and controls are real HTML, separate from the image.

The mobile and desktop wireframes in `docs/wireframes/` are deterministic, editable SVG drawings, with PNG previews. They depict interface layout and do not substitute for the production character asset.
