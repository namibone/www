NamibOne is an independent prototype for exploring public-service journeys in Namibia. The demo uses example services, departments, records and fees. Use the pilot to try an interaction and tell the project team where you got stuck.

| Area | What you can try | Planned capabilities |
| --- | --- | --- |
| Companion | Type a supported service question and follow a catalogue link. | Generative replies through a verified backend. |
| Citizen and staff workspaces | Create a sample request, track it and update its status in the same tab. | Verified sign-in, real records and staff access controls. |
| Payment demo | Review a sample payment and read a simulation receipt. | Approved payment integrations and live processing. |
| N1 Wallet | View a demo balance and activity, and open an action preview. | Wallet registration, identity verification and live transactions. |

Use preset values throughout the demo. Keep identity documents, passwords, account numbers and payment details out of the demos and public feedback.

## Languages

These guides are available in English. Namibian-language editions can be added as each guide is translated and reviewed against the same pilot task.
