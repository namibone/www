Follow a sample business enquiry from the Companion to the application tracker. Allow about five minutes. Use one browser tab for the demo and leave the preset values in place unless the guide asks you to change them.

## Find a service

1. Open [NamibOne](https://namibone.com/). In the Companion prompt, type **business registration** and select **Send message**.
2. Follow the service link to **Business registration**. You can also open [Business registration](https://namibone.com/service-business.html) directly or find it in the [service catalogue](https://namibone.com/services.html).
3. Select **Start sample request**. The wizard opens with the business service selected.

## Create and track a sample request

1. Select **Continue**. For **Request type**, choose **Information enquiry**, then select **Continue** again.
2. Review the preset details and check the sample-request confirmation box. Select **Create sample request**.
3. On **Sample request created**, note the `DEMO-` reference and select **Track sample request**.

**Expected result.** The application detail shows your `DEMO-` reference and **Received** status. The sample record is stored in the browser tab that created it.

## If you get stuck

- If the Companion returns a general suggestion, use the direct service link above.
- If the wizard stays on the review step, check the confirmation box and select **Create sample request** again.
- If the tracker cannot find your reference, return to the original NamibOne tab. If the sample workspace was reset, create a new request there.

[Continue to the pilot staff guide](../staff/) to update your sample request in the same tab.
