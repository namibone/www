## My sample reference is missing

Use the same NamibOne tab in which you created the request. Open [My applications](https://namibone.com/citizen-applications.html) and clear the status filter. If the demo says that browser storage is unavailable, try in a standard browsing window with site storage enabled.

## The Companion missed my question

Try a short service name such as **business registration**. You can reach the same sample journeys directly from the [service catalogue](https://namibone.com/services.html).

## I opened a wallet action and saw a preview message

That is the expected result. Close the dialog to return to [the dashboard](https://n1wallet.net/portal.html). The [wallet guide](../n1-wallet/) explains what you can try there.

## Report a documentation issue

Tell us the guide title, the step, what you expected and what appeared on screen. Include the device and browser if the issue concerns layout or navigation. Use example references and remove personal or account details from screenshots.

[Open a documentation issue on GitHub](https://github.com/namibone/www/issues/new?title=Docs%3A%20).
