Explore the N1 Wallet dashboard and see how a balance, transactions and account status may be presented. Allow about three minutes. The preview uses illustrative amounts in Namibian dollars (NAD).

## Explore the dashboard

1. Open [N1 Wallet](https://n1wallet.net/) and select **Open wallet preview**.
2. Find **Demo available balance · NAD**, then read the **Example transactions** section to see sample credits and debits.
3. In the balance card, select **Send**, **Receive**, or **Pay**. Read the preview dialog, then select **Close**.
4. Under **Account preview**, find **Wallet status**. It reads **Demo only**.

**Expected result.** You can identify the demo balance, find example transactions, and open and close a preview dialog. The amounts remain illustrative throughout the walkthrough.

## If you get stuck

- Open the [wallet dashboard preview](https://n1wallet.net/portal.html) directly if the homepage link is hard to find.
- Scroll through the dashboard on a phone to reach **Example transactions** below the balance.
- For details on registration, identity checks and future payment features, see the [pilot scope](../pilot/).
