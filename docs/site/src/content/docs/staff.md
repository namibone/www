title: Pilot staff
description: Update a sample case in the NamibOne staff queue and confirm the citizen-facing status.
---

Try the staff side of a sample request and confirm that the citizen view reflects your update. Have the `DEMO-` reference from the [citizen guide](../citizens/) ready. Keep using the same NamibOne browser tab for both workspaces.

## Update a case

1. In the tab that created the sample request, open the [staff case queue](https://namibone.com/staff-cases.html). You can paste this address into that tab’s address bar.
2. Find your `DEMO-` reference and open the case. Set the status filter to **All statuses** if a filter hides it.
3. In the case detail, choose **Completed** in the status list and select **Save sample status**. Look for the confirmation beside the control.
4. In the same browser tab, open [My applications](https://namibone.com/citizen-applications.html) and reopen the same `DEMO-` reference.

**Expected result.** The citizen application detail now shows **Completed**. The update applies to the sample data in that browser tab.

## If you get stuck

- Select **All statuses** and **All departments**, then check that you are in the original tab.
- If the sample was reset, repeat the citizen guide to create a new reference.
- If you only need to explore the staff interface, open one of the preset cases and follow the same update steps.
